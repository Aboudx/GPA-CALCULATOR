# 🎓 GPA Calculator

![Badge](https://img.shields.io/badge/GPA%20Calculator-Desktop%20Application-0E4CB5?style=for-the-badge)

A modern Windows Forms application built with **C# (.NET Framework 4.8)** that helps university students calculate their **Semester GPA**, **Updated Cumulative GPA**, and determine the **required GPA** needed to achieve a desired academic goal.

Designed with a clean interface inspired by **Al-Qalamoon University** and developed with a strong focus on clean code, user experience, and practical academic assistance.

</div>

---

# 📖 About the Project

This project was developed with one primary goal:

> **Helping university students make better academic decisions and improve their academic performance.**

Many students know the GPA they wish to graduate with, but they often don't know **what they actually need to achieve in the upcoming semester** to reach that goal.

This application solves that problem by allowing students to:

- Calculate their **Semester GPA**
- Calculate their **Updated Cumulative GPA (CGPA)**
- Set a **Target GPA** and instantly discover the GPA required in the next semester to achieve it

By simply entering their completed hours, current CGPA, and semester courses, students receive accurate calculations that help them plan their academic progress with confidence.

The project was created not only as a programming exercise, but as a practical tool intended to benefit my fellow university students.

# ✨ Features

## 📚 Semester GPA Calculator

- Add 10 courses Maximum
- Edit existing courses
- Delete courses
- Automatic letter grade conversion
- Calculate Semester GPA
- Calculate Updated Cumulative GPA
- Calculate Total Completed Credit Hours

---

## 🎯 Target CGPA Calculator

Students can enter:

- Desired Target CGPA
- Upcoming Semester Credit Hours

The application instantly calculates the GPA required to reach the desired cumulative GPA.

The result is also classified as:

- ✅ Achievable
- 🟡 Challenging
- ❌ Not Achievable

---

## ✅ Smart Validation

The application validates all important inputs in real time.

Validation includes:

- GPA range (0.00 – 4.00)
- Grades (0 – 100)
- Credit Hours
- Required Academic Information

This prevents invalid calculations and improves user experience.

---

## 🔔 Custom Notification System

A custom notification component developed specifically for this project.

Features include:

- Success notifications
- Warning notifications
- Error notifications
- Automatic hide after 3 seconds
- Manual close button

---

## 🌐 Built-in User Guide

The application includes a complete built-in guide explaining how to use every calculator.

Supported languages:

- 🇬🇧 English
- 🇸🇦 العربية
